Rúbrica de autoevaluación: ¿Cómo estoy diseñando mi presentación?
Actividad interactiva de reflexión para estudiantes que están preparando las diapositivas de una exposición oral. Se basa en las recomendaciones de la charla «Cómo presentar la información».
Qué permite hacer
Elegir uno de cuatro niveles para cada uno de los siete criterios.
Anotar mejoras concretas en cada criterio (opcional).
Responder tres preguntas finales de reflexión.
Copiar toda la autoevaluación al portapapeles para pegarla en un documento o mensaje.
Borrar las respuestas con confirmación.
Privacidad: la página no requiere cuentas, no tiene seguimiento analítico ni envía respuestas a servidores. Tampoco guarda respuestas al recargar o cerrar.
Publicar en GitHub Pages
Crear un repositorio público en GitHub, por ejemplo `rubrica-presentaciones`.
Subir `index.html` a la raíz del repositorio (y opcionalmente este README).
En Settings → Pages, elegir Deploy from a branch.
En Branch, elegir `main`, carpeta `/ (root)`, y guardar.
Cuando GitHub termine de publicar, la URL habitual será `https://TU-USUARIO.github.io/rubrica-presentaciones/`.
No necesita compilación ni dependencias. También puede abrirse `index.html` de forma local; el botón Copiar utiliza el portapapeles moderno en HTTPS y tiene un método alternativo para navegadores que lo permiten.
Personalización
Cambiar los textos de los criterios: editar la lista `criteria` al final de `index.html`.
Cambiar los niveles: editar la lista `levels`.
Cambiar colores: editar las variables CSS dentro de `:root`.
Nota pedagógica
La actividad no calcula una nota ni asigna puntajes. Se centra en identificar mejoras durante la etapa de diseño, antes de la exposición oral.
